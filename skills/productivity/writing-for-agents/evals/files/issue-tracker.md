# Issue tracker

Issues are tracked on GitHub in this repository.

## Type roles

| Type | Role |
| --- | --- |
| Epic | Container; its work lives in child issues |
| Feature | Deliverable behaviour; may have child tasks |
| Task | One unit of implementation |

## State mapping

| State | Meaning |
| --- | --- |
| Open | Not started or in progress |
| Closed, merged pull request linked | Done |
| Closed, no pull request | Will not do; the closing comment states why |

## Verification status

A dependency counts as merged only when its pull request is merged into `main`. A closed issue alone is not evidence.
