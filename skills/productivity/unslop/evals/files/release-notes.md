# Release Notes For Version 2.4

Great question — what’s new in 2.4? Let’s delve into it!

## Highlights

- **Performance:** Performance was improved significantly, showcasing our commitment to speed.
- **Reliability:** Reliability is enhanced across the board.

The new scheduler isn't just faster, but smarter — it leverages a pivotal caching layer that serves as the bedrock of the system. In order to upgrade, run `npm install scheduler@2.4`; the config file is migrated automatically by the installer.

Queries are now validated at build time. Experts believe this is a testament to the robust landscape of modern tooling, from parsing to deployment.

I hope this helps! Let me know if you have any questions.
