# Triage labels

The skills speak in terms of seven canonical triage roles. This file maps each role to the actual label string used in this repo's issue tracker.

| Role type | Canonical role | Label in this tracker | Meaning |
| --- | --- | --- | --- |
| Category | `bug` | `type: bug` | Something is broken |
| Category | `enhancement` | `type: feature` | New feature or improvement |
| State | `needs-triage` | `status: triage` | Maintainer needs to evaluate this issue |
| State | `needs-info` | `status: waiting` | Waiting on reporter for more information |
| State | `ready-for-agent` | `status: agent-ready` | Fully specified, ready for an AFK agent |
| State | `ready-for-human` | `status: human` | Requires human implementation |
| State | `wontfix` | `status: declined` | Will not be actioned |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.
